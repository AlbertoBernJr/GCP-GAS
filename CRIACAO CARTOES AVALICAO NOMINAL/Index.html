📇 CRIAÇÃO CARTÕES AVALIAÇÃO NOMINAL

Sistema automatizado para geração de cartões de avaliação nominal

📌 Sobre o projeto

Ferramenta que automatiza a criação de cartões de avaliação nominal, integrando dados de planilhas Google e gerando documentos prontos para impressão ou envio digital. Reduz drasticamente o tempo de produção manual e elimina erros de digitação.

Funcionalidades principais:
✅ Leitura automática de dados do Google Sheets
✅ Geração em massa de cartões personalizados
✅ Formatação profissional com layout definido
✅ Exportação para PDF ou impressão direta
✅ Interface simples para configuração

📊 Google Sheets 📜 JavaScript ⚡ Apps Script 📄 PDF 🎨 HTML/CSS
