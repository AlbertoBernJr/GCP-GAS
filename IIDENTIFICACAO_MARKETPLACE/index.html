🔍 IIDENTIFICACAO MARKETPLACE

Automação inteligente para identificação de produtos em marketplaces

📌 Sobre o projeto

Sistema híbrido (Python + JavaScript) que automatiza a identificação e classificação de produtos em marketplaces. Combina web scraping, APIs do Google Sheets e interface web para dashboards em tempo real.

Funcionalidades principais:
✅ Coleta automática de dados de produtos
✅ Integração com Google Sheets (leitura e escrita)
✅ Classificação por similaridade textual
✅ Notificações via e‑mail e Telegram
✅ Painel de controle em JavaScript puro

🐍 Python 📜 JavaScript 📊 Google Sheets API 🌐 BeautifulSoup ⚡ Apps Script
