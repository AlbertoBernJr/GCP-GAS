🔍 IDENTIFICACAO MARKETPLACE

Automação inteligente para identificação de produtos vendidos em marketplaces

📌 Sobre o projeto

Sistema híbrido (Python + JavaScript) que automatiza a identificação e classificação de produtos em marketplaces. Combina web scraping, APIs do Google Sheets e interface web para dashboards em tempo real.

Funcionalidades principais:
✅ Coleta automática de dados das vendas
✅ Integração com Google Sheets (leitura e escrita)
✅ Classificação por similaridade textual
✅ Adição do relatório de vendas na planilha google
✅ JavaScript realiza toda a lógica de comparação e identificação dos compradores

Python Selenium Google Sheets API Pandas Microsoft Excel
