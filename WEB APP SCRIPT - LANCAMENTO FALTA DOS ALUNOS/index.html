📊 WEB APP SCRIPT – LANCAMENTO FALTA DOS ALUNOS

Aplicativo web para registro de faltas com integração ao Google Sheets

📌 Sobre o projeto

Aplicativo web desenvolvido com Google Apps Script para automatizar o lançamento de faltas de alunos, oferecendo interface amigável, filtros e gravação direta em planilha Google. Elimina a necessidade de preenchimento manual e reduz erros.

Funcionalidades principais:
✅ Verificação de permissões de acesso
✅ Interface de seleção de alunos
✅ Aplicação de filtros dinâmicos
✅ Marcação de faltas com um clique
✅ Atualização automática da planilha
✅ Contador de faltas por aluno

📜 JavaScript ⚡ Apps Script 📊 Google Sheets 🌐 HTML/CSS
