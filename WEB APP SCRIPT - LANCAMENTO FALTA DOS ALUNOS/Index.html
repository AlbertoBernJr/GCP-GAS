📇 WEB APP SCRIPT - LANCAMENTO FALTA DOS ALUNOS

Aplicativo web para lançamento de faltas dos alunos

📌 Sobre o projeto

Aplicação web desenvolvida com Google Apps Script para registrar e acompanhar o lançamento de faltas dos alunos de forma rápida e integrada ao Google Sheets.

Funcionalidades principais:
✅ Interface web responsiva
✅ Integração com planilha Google
✅ Registro de faltas por turma e data
✅ Geração de relatórios automáticos
✅ Controle de acesso simples

📊 Google Sheets 📜 JavaScript ⚡ Apps Script 🌐 HTML/CSS
